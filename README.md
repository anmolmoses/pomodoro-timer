# FocusFlow

A beautiful Pomodoro timer with dark glassmorphism design, built with React, Framer Motion, and Tailwind CSS.

## Features

- 🎯 Circular SVG progress ring with smooth animations
- 🌙 Dark/light theme with localStorage persistence
- ⌨️ Keyboard shortcuts (Space, R, S)
- ⚙️ Configurable work/break durations
- 📱 Fully responsive (320px mobile → desktop)
- 🎉 Session completion celebrations
- 🔥 Streak tracking with flame animation
- 💫 All animations powered by Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

## Keyboard Shortcuts

| Key | Action |
|-------|---------------|
| Space | Start / Pause |
| R | Reset |
| S | Skip phase |

## Tech Stack

- React 18 + TypeScript
- Framer Motion
- Tailwind CSS
- Vite
- Lucide React icons
